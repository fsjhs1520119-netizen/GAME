    🌸 遊戲簡介 (GAME OVERVIEW) 🌸
     `《銀河線間的微光》` 是一款專為音樂學習者與遊戲玩家打造的雙重體驗平台！💖✨  
    結合了治癒舒壓的 奶茶粉手帳剪貼簿風格 (PASTEL SCRAPBOOK) 以及高對比度的 黑框霓虹熔岩疾跑 (NEON LAVA RUNNER)，讓原本枯燥難懂的樂理與五線譜視讀，變得無比有趣且充滿挑戰性！🎶⚡

   🎼 核心特色 (KEY FEATURES) 🎼
🎹⚡ 五線譜 ⚡ 簡譜秒讀特訓器 (STAFF TO JIANPU CONVERTER)
🎼 將艱深的五線譜即時轉化為直覺的數字簡譜 `1 2 3 4 5 6 7`！
🎯 提供 4 大循序漸進的難度關卡：`線上音 (LINE NOTES)`、`間上音 (SPACE NOTES)`、`中央 C (MIDDLE C)` 以及 `全音域大挑戰 (FULL RANGE)`！
👨‍🏫📢 嚴師即時講評機制 (STRICT MASTER FEEDBACK)
⚡ 嚴導師 (MASTER STRICT) 會在您答錯或逾時的瞬間進行即時糾正與講評！
💡 絕不給您猶豫的時間，鍛鍊最精準的視讀條件反射！
🌸✂️ 柔和手帳剪貼簿美學 (PASTEL SCRAPBOOK DESIGN)
🎨 採用舒適優雅的色調：`奶白 (MILK CREAM)`、`奶茶米 (WARM BEIGE)` 與 `柔粉 (SOFT PINK)`！
🖼️ 搭配紙膠帶貼紙、拍立得相框、紙張撕邊紋理與手作戳章，營造極致質感！
🌌🏃‍♂️ 黑框霓虹極速跑酷 (NEON LAVA ESCAPE RUNNER)
💥 內嵌於質感相框內的 2D 橫向捲動跑酷小遊戲！
🔥 從左向右極速衝刺，考驗連跳與閃避刺柱、雷射光束及下方不斷上升的紅色熔岩！

👎 遊戲缺點與挑戰 (CONS & CHALLENGES) 👎
💥🔥 霓虹疾跑具備相當難度 (HIGH RUNNER DIFFICULTY)
⚡ 上升熔岩與密集機關較為考驗反應速度，對非動作遊戲玩家來說極具挑戰性！
📚🎼 題庫音域可持續擴充 (EXPANDABLE MUSIC LIBRARY)
🎹 目前主要針對常用音域進行單音訓練，未來可加入更多完整古典或流行曲目的秒讀練習！
📲💻 建議使用實體鍵盤 (KEYBOARD RECOMMENDED)
⌨️ 雖然支援行動端觸控按鈕，但使用電腦實體鍵盤遊玩橫向跑酷能獲得最佳的操作精準度！

🕹️ 操作指南 (CONTROLS & HOW TO PLAY) 🕹️
🏃‍♂️ 霓虹熔岩疾跑 (NEON LAVA ESCAPE)
⌨️ `[ 空白鍵 SPACE ]` / `[ 上方向鍵 ↑ ]` : 跳躍 / 二段跳 🏃‍♂️💨
⌨️ `[ A ]` / `[ D ]` / `[ 左/右方向鍵 ← → ]` : 左右移動 / 控制速度 ⬅️➡️
🏆 終極目標：從左向右全力衝刺，閃避障礙物，千萬不要掉入熔岩坑中！🔥💥
🎹 五線譜秒讀特訓 (SIGHT-READING TRAINER)
🖱️ 滑鼠 / 觸控：觀察五線譜上的音符位置，在倒數結束前快速點擊對應的簡譜數字按鈕 `1` 到 `7` 即可計分！⚡
